## 1. 대시보드 `/` (60초) — "시민이 10초 안에 읽는 화면"
- 배너: **"기관이 약속한 조치, 그 뒤에도 보도됐을까요?"** — 기관 대응 발언 기사 1,559건 → 사건 90건 → **후속보도 확인 62건(69%, 자동 판정)**.
  "합성 데이터가 아닙니다. 빅카인즈 인용문 검색·뉴스 검색·이슈 랭킹·키워드 트렌드를 8,500회 호출해 2023~2025년 전국 재난·안전 사건을 모았습니다. 자동 판정은 라벨 대비 정밀도 0.53·재현율 0.79이고, 라벨 기준으로는 90건 중 42건(47%)입니다." ← 69% 를 그대로 두지 말고 반드시 이 문장을 붙인다.
- KPI 타일: 추적 90 / 후속보도 확인 62 / 발표 기한 경과 / **기관 발표 확인 4** / 보도된 인명 피해(제목·발췌 정규식, 추정 없음).
- 시계열: 월별 발생 사건(막대)과 후속보도 기사(선). 2023-07 집중호우, 2025-03 산불 구간을 가리키며 "사고 직후 보도가 몰리고, 조치 보도는 그 뒤에 띄엄띄엄 옵니다."

- **기관별 후속보도 현황**: 후속보도가 확인된 기관이 위, 아직 확인되지 않은 기관이 아래(기관 60곳). 상위 경기도 6/6, 국토교통부 4/5, 인천시 3/3, 한국철도공사 3/3. "잘한 기관이 위에 옵니다. 기관명을 누르면 그 기관 사건만 봅니다."

## 4. 근거·불확실성 + 기관 발표 확인 `/events/262/evidence` (50초) — 이번 피드백의 핵심
- **서울 지하철 5호선 전동차 방화 화재**(서울시, 2025-05-31, 상태 `판단 불가`). 또는 **평택 통복터널 SRT 단전 사고**(국토교통부, `후속보도 부족`) — 정책브리핑 「통복터널 사고 민간자문단 특별위원회 활동 결과 발표」(2023-02-28)가 붙는다.
- 판정 규칙 상자: 마지막 후속 기사일, 규칙 이름·임계값. 신호 표: 발췌 문장과 신뢰도.
- **「기관 발표 확인」 패널**: 트리거(후속보도 부족 + 90일 경과) → 서울특별시 보도자료 게시판 → 「(자료제공) 오세훈 시장, 5호선 열차 방화 관련 "선거 전까지 시민 안전 활동 강화" 긴급 지시」(2025-05-31, 매칭 0.6, 링크).
  "뉴스에는 후속보도가 없었지만 기관은 발표했습니다. 이게 이 서비스가 찾는 사실입니다. 상태는 바꾸지 않고 보조 근거로만 붙입니다."
- 규칙 설명 한 줄: 뉴스 원문 크롤링은 없고, 공공기관 공식 게시판만, 트리거된 사건만(90건 중 19건), robots.txt·2초 간격. 실험 DB 기준 기관 발표 확인 4건. 정책브리핑 매칭이 일반어로 다른 해의 발표를 잡는 경우가 있어(대덕구 호우 ↔ 2026 호우 보도자료) 통복터널·5호선처럼 구체적인 건으로 시연한다.
- 면책 문구: "보도가 없다는 사실은 조치가 없었다는 근거가 아니라, 확인이 필요하다는 신호입니다."

## 예상 질문
- **69%가 진짜인가?** → 아닙니다. 규칙 자동 판정이고, 라벨과 비교하면 정밀도 0.53입니다. 라벨 기준 실제 후속보도는 90건 중 42건(47%)이며, 틀린 29건은 대부분 같은 지역·같은 재난어의 다른 사건 기사가 군집에 섞인 경우입니다(군집 정밀도 0.58). 틀린 사례를 숨기지 않고 보여 드립니다.
- **라벨은 누가 붙였나?** → Claude 에이전트 16개가 붙였고(후속보도 5 + 반박 검증 5 + 군집 4 + 기관 2), 사람 라벨이 아닙니다. CSV 에 근거 기사와 메모가 있어 사람이 검토·수정할 수 있습니다.
- **사건 90건은 어떻게 골랐나?** → 자동 시드 150건을 에이전트가 사건명·시설·기관·질의로 다듬고, 예방·정책 일반 기사 28건, 중복 16건, 범죄·해외·집계형 16건을 뺐습니다(`docs/EXPERIMENT.md` §4).
- **크롤링 아닌가?** → 언론사 원문은 어떤 경우에도 읽지 않습니다. 공공기관 공식 보도자료 게시판만, 트리거된 사건만, 목록 제목·날짜·링크 위주로 읽고, 뉴스 도메인은 코드에서 거부합니다(테스트 고정).
- **LLM 없이 어떻게?** → 약속 추출·후속 신호 분류·초안은 규칙 어댑터(`rules-v1`)입니다. 키가 오면 `LLM_MODE=live` 로만 바꾸면 됩니다(프롬프트·스키마·검증 코드 동일).
- **보도가 없으면 안 한 것인가?** → 아닙니다. 상태는 `후속보도 부족`이고, 기관 게시판에서 발표가 확인되면 그 사실을 함께 보여 줍니다.
